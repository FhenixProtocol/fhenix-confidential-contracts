# Security Policy

## Supported versions

| Version | Supported                                                     |
| ------- | ------------------------------------------------------------- |
| 1.x     | Yes                                                           |
| < 1.0   | No. Pre-1.0 releases predate the audit fixes; upgrade to 1.x. |

## Reporting a vulnerability

**Do not open a public issue.** Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/FhenixProtocol/fhenix-confidential-contracts/security/advisories/new).

Please include:

- the affected contract(s) and version or commit,
- a description of the issue and its impact,
- steps or a test case that reproduces it.

We will acknowledge the report, keep you informed while we investigate, and credit you in the
advisory unless you prefer otherwise.
